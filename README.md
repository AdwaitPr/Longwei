# Longwei 🐉

> Scroll-driven 3D landing page: a celestial jade ring uncoils into a realistic Chinese dragon.

Longwei is an interactive 3D WebGL web application crafted with **React 19**, **Three.js**, **GSAP ScrollTrigger**, and **Tailwind CSS**. It delivers an immersive, cinematic narrative that transforms a primordial artifact into a mythical dragon as the user scrolls.

---

## ✨ Features

- **Cinematic 3D Dragon Transformation**: Dynamic spline generation, vertex deformation, procedural flame breath, and environment lighting using Three.js.
- **Scroll-Driven Choreography**: Synchronized with GSAP ScrollTrigger and Lenis smooth scrolling for high-precision, frame-rate independent animations.
- **Rich Narrative Overlay**: Historical chapter sections, artifacts gallery, and typography inspired by Chinese mythology and classical heritage.
- **Responsive & Accessible**: Optimized for mobile and desktop screens with `prefers-reduced-motion` accessibility support.
- **Performance Optimized**: Procedural particle systems, custom normal maps, and lazy asset loading.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **3D & Graphics**: [Three.js](https://threejs.org/)
- **Animation**: [GSAP](https://gsap.com/) & ScrollTrigger
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (version 18+ recommended) and npm installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AdwaitPr/Longwei.git
   cd Longwei
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at the local server URL (typically `http://localhost:5173`).

---

## 📦 Building for Production

To create an optimized production build:

```bash
npm run build
```

Preview the build locally:

```bash
npm run preview
```
